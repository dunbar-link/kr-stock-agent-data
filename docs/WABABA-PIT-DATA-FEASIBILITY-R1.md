## 1. 가장 중요한 발견 — bias 를 실제로 제거할 수 있다

| 검사 | 결과 | 의미 |
|---|---|---|
| 과거 시점 상장목록 | `get_market_ticker_list(t)` 가 **그 시점 목록**을 반환 | point-in-time universe 가능 |
| 2010-01-04 | KOSPI 925 / KOSDAQ 1,036 | 현재(943 / 1,820)와 실제로 다름 = 진짜 과거 목록 |
| 상장폐지 종목 가격 | 2016·2020·2023 표본 **5/5 전부 조회 성공** | survivorship bias 제거 가능 |
| 2016-01-04 universe 2,041 중 현재 소멸 | **305종목** | 이걸 빼면 성과가 부풀려진다 |
| 2020-01-02 universe 2,324 중 현재 소멸 | 236종목 | |
| 2023-01-02 universe 2,558 중 현재 소멸 | 194종목 | |

**즉 "지금 살아있는 종목만으로 과거를 시뮬레이션하는" 흔한 오류를 구조적으로 피할 수 있다.**
이것이 이 프로젝트에서 가장 값진 확인이다.

### 1-1. look-ahead bias 도 구조적으로 없다

KRX 가 매일 공표하는 PER/PBR/EPS/BPS 는 **그 날 시점에 공시돼 있던 최신 재무**로 계산된다.
나중에 정정된 재무로 과거를 다시 계산하지 않는다. 따라서 이 값을 그대로 쓰면
"2008년 판단에 2010년에 수정된 숫자를 쓰는" 오류가 원천적으로 발생하지 않는다.

반면 **DART API 는 위험하다**: 특정 사업연도를 조회하면 *가장 마지막 정정본*을 준다.
로컬 캐시 실측에서도 FY2024 파일의 접수일이 2025-08-14(정정), FY2022 파일 중 11.8%가
FY+1 하반기 이후 접수였다. DART 를 쓸 때는 `rcept_no` 앞 8자리(접수일)로 필터링해야 한다.

## 2. 데이터별 실제 가용 범위 (실측)

| 데이터 | 최초 | 비고 |
|---|---|---|
| KOSPI 지수 | **1990-01-03** (9,444 거래일) | benchmark 충분 |
| KOSDAQ 지수 | **1996-07-01** (7,536 거래일) | benchmark 충분 |
| 시가총액·종가·상장주식수 | **1999-01-04** (1,258종목) | 충분 |
| 상장목록(PIT) | 1999~ | 충분 |
| **PER** | 2000~ (426종목) → 2003 이후 1,000+ | |
| **PBR / BPS** | **2007 이전 결손** ← 결정적 제약 | |
| DART 재무(EBIT 등) | **FY2022 ~ FY2025 만** | 로컬 캐시 13,356 파일 |

### 2-1. 결정적 제약 — PBR(=BPS) 결손

마법공식 근사판의 수익성 지표는 `ROE = EPS / BPS` 다. BPS 가 없으면 계산이 불가능하다.
실측 PBR 유효 종목수:

```
1999-01-04   PER>0 =     0   PBR>0 =     0     → 사용 불가
2000-01-04   PER>0 =   426   PBR>0 =     0     → 사용 불가
2003-01-02   PER>0 = 1,093   PBR>0 =   601     → 부분(약 35%)
2005-01-03   PER>0 = 1,110   PBR>0 =   651     → 부분
2007-01-02   PER>0 = 1,197   PBR>0 = 1,623     → 양호 ✅
2009-01-02   PER>0 = 1,179   PBR>0 = 1,711     → 양호
2010-01-04   PER>0 = 1,058   PBR>0 = 1,695     → 양호
```

실제 스냅샷에서도 1999~2002 구간은 **적격종목 0개**로 확인됐다(`--mode coverage`).
2026 구간은 스냅샷 2,770행 중 **적격 약 1,500개**로 정상 동작한다.

### 2-2. ROE 항등식 검증 — 근사공식이 성립한다

`PBR / PER = (P/B) / (P/E) = E/B = ROE` 가 실데이터에서 성립하는지 직접 검증했다.

```
2010-01-04   n=1,057   |오차|<1% 비율 = 95.6%
2016-01-04   n=1,278   |오차|<1% 비율 = 98.4%
2023-01-02   n=1,608   |오차|<1% 비율 = 93.5%
2026-08-07   n=1,543   |오차|<1% 비율 = 89.6%
```

→ KRX 공표값만으로 ROE 를 신뢰성 있게 복원할 수 있다.
→ **저장소가 이미 갖고 있는 `approx` 모드(ROE·PER 마법공식)를 장기 PIT 로 재현 가능하다.**

## 3. 최종 판정 — 백테스트 가능 구간

| 구간 | 공식 | 판정 |
|---|---|---|
| **2007-01 ~ 2026-08 (약 19.6년)** | 근사 (ROE·PER) | ✅ **PRIMARY — 이 구간으로 연구한다** |
| 2003-01 ~ 2006-12 (4년) | 근사 | ⚠️ PBR 커버리지 35~50% — 보조 참고만 |
| 1999-01 ~ 2002-12 (4년) | — | ❌ 불가 (BPS 없음) |
| **2023-04 ~ 2026-08 (약 3.3년)** | **원전 (EBIT/EV)** | ⚠️ 기간 부족 — 교차검증용 |
| 1990-01 ~ 현재 | benchmark 지수만 | ✅ 비교 기준으로 사용 가능 |

원전 공식 3.3년의 근거: 로컬 DART 캐시 최초 사업연도 = FY2022,
FY2022 사업보고서 접수일 중앙값 = **2023-03-21** → 그 이전에는 판단 근거가 없다.

## 4. 원전 공식 구간을 늘리려면 (무료 경로가 먼저다)

**유료 데이터를 사기 전에 무료로 할 수 있는 것이 남아 있다.**

DART OpenAPI `fnlttSinglAcntAll` 는 **사업연도 2015년부터** 제공한다(무료, 일 20,000콜 한도).
현재 캐시는 FY2022~2025 뿐이므로 **FY2015~FY2021 (7년)을 추가로 받아올 수 있다.**

- 예상 콜 수: 약 2,600사 × 7년 × 2(CFS/OFS) ≈ **36,000콜** → 하루 한도 안에서 2~3일
- 비용: **0원**
- 얻는 것: 원전 공식 백테스트 구간 3.3년 → **약 10년**

단, 두 가지 제약이 남는다.

1. **상장폐지 기업 누락**: 현재 `_cache/dart-corp-codes.json` 은 3,960건이고 `stock_code` 필드가
   비어 있어 상장기업 매핑이 없다. DART 전체 corpCode(약 10만건)를 다시 받아
   과거 상장기업(폐지 포함)까지 확보해야 survivorship 이 제거된다.
2. **정정공시 문제**: 특정 연도 조회 시 최종 정정본이 온다. `rcept_no` 접수일로
   "결정 시점 t 이전에 접수된 것만" 필터링해야 한다(구현 필요).

**결론: 유료 데이터 구매는 지금 판단할 사안이 아니다.** 무료 DART 확장(FY2015~)과
근사공식 19년 백테스트를 먼저 끝내고, 그 결과가 사업적으로 유의미할 때만 유료를 논의한다.
→ `REQUIRED_BLOCKER` 아님 / `DATA_GAP` 으로 분리.

## 6. 이 단계에서 확정된 설계 결정

1. **주 연구 공식은 근사(ROE·PER)** — 원전이 아니라고 문서·홈페이지에 명시한다.
2. **원전(EBIT/EV)은 2023~2026 교차검증용** — 두 공식의 상위종목 일치율을 측정해
   근사가 원전의 합리적 대리인지 정량 확인한다(추가 연구항목).
3. **월 단위 스냅샷** — 보유기간 후보(2·3·6·9·12·18·24·36개월)에 충분하다.
   현재 운영의 50거래일은 ≈ 2.4개월이므로 2개월/3개월로 협공해 근사한다(일 단위 재현 아님을 명시).
4. **상장폐지 처리**: 마지막 관측가 × (1 − haircut) 청산. haircut 0% / 30% / 100% 민감도 필수.
5. **비용 기본값**: 편도 수수료 15bp + 매도 거래세 20bp. 0bp / 고비용 시나리오 병행.
